【任务描述】将Markdown文件转换为HTML格式，同时严格保留原文档的结构。

1. 转换过程中必须完整保留原文件的层级、标题、表格等结构，确保HTML中的标题标签（h1-h6）与Markdown中的#号数量对应。
2. 在转换前，先删除Markdown源文件中的样式标记、无效链接、图片占位符等无用内容。
3. 生成的HTML文件需包含基础的CSS样式，使表格和标题有清晰的视觉区分。
   【输出要求】输出可直接在浏览器中打开的HTML文件。
