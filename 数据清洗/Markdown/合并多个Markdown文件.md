你现在是一名技术文档工程师。请帮我编写一个合并多个Markdown文件的脚本：
【任务描述】将指定文件夹下的多个Markdown文件按顺序合并为一个完整文档。
【输入信息】文件夹路径：[填写路径]，文件合并顺序：[按文件名排序/按指定列表]。
【处理规则】
1. 合并时，每个原文件的标题层级保持不变，不得因为合并而改变原有的#号数量。
2. 在合并前，先对每个文件进行预处理：删除样式标记、无效链接、重复的页眉页脚等冗余内容。
3. 在两个文件之间插入分页符（如HTML的<hr>标签或Markdown的---分隔线）。
4. 严格保留每个文件中的表格、代码块等结构，确保合并后格式不混乱。
   【输出要求】合并后的文件保存为"merged_document.md"，并打印合并过程中处理的文件数量。
   【代码约束】代码轻量且简洁，包含文件不存在时的异常处理，关键逻辑添加注释。
